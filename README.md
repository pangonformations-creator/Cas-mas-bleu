# Le Mas Bleu — TD Marketing digital

Site statique prêt pour GitHub Pages. Cette archive contient la version du 4 novembre 2026, avec la base clients fictive en CSV et Excel.

## Mise en ligne

1. Décompressez cette archive.
2. Déposez son contenu à la racine de votre dépôt GitHub, en remplaçant les anciens fichiers. Le fichier index.html doit être directement à la racine.
3. Dans Settings > Pages, choisissez Deploy from a branch, votre branche principale et le dossier / (root), puis enregistrez.
4. Ouvrez le lien GitHub Pages fourni par GitHub après le déploiement.

Aucune installation ni compilation nécessaire. Les liens et les ressources sont relatifs pour fonctionner dans un sous-dossier GitHub Pages.

## Parcours

Étapes accessibles : 01 Cibles et positionnement, 02 Audit et conversion, 03 SEO, 04 Emailing.
Étapes fermées dans la navigation : 05 Réseaux sociaux, 06 Recommandation finale, 07 Visibilité dans les IA.
Les pages fermées sont présentes dans les fichiers et restent accessibles par leur URL directe.

Le TD SEO comprend la création d’une page pilier avec Google Antigravity.
Le TD Emailing propose une base de 100 clients fictifs et la création d’un parcours automatisé dans Brevo.
Les données fictives servent à l’import et à la segmentation. Les envois de test utilisent les adresses autorisées du groupe ou de l’enseignant.
